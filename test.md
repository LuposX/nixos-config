

# Response to Supervisor Feedback: Revised Methodology

## 1. Summary of Changes

| Feedback Topic | Original Approach | Revised Approach |
|----------------|-------------------|------------------|
| **Optimization objective** | $\sum_t \|\text{softmax}(o_t^{\text{free}}) - \text{softmax}(o_t^{\text{faulty}})\|_2^2$ | Concatenated representation: attention-pooled hidden states + mean-pooled pre-softmax logits; L2 distance in combined space |
| **Sentence encoder** | Sentence-BERT (2019, MTEB ~56) | Qwen3-Embedding-0.6B (2025, MTEB 64.34, Apache-2.0, same tokenizer family) |
| **Teacher forcing reference** | Fixed reference $r$ generated from fault-free model | Random fixed sequence |
| **Sensitivity weighting motivation** | "Too many parameters for exhaustive coverage" | Skew toward high-sensitivity weights to model **in-distribution** faults; dead-region faults produce garbled outputs irrelevant to safety |
| **Temperature** | Jointly learned $\tau$ via $\tanh(\phi)$ | Retained from DLMI; ablation against fixed annealed schedule |
| **Pooling** | Mean pooling (implicit) | **Attention pooling** as default; mean/max as ablations |

## 2. Phase 1: Offline Test Pattern Generation

### 2.1 Differentiable Input Representation (SDoT)

Unchanged. The input is a learnable logit matrix $Z \in \mathbb{R}^{N \times |V|}$. Each row is passed through a tempered softmax to produce a soft token distribution $\tilde{x}_i$, embedded via $\tilde{E}(\tilde{x}_i) = W_E \cdot \tilde{x}_i$. Fully differentiable.

**Temperature.** Retain the DLMI formulation:
$$\tau = \epsilon + \tau_0 \cdot (1 + \tanh(\phi))$$
with $\phi \in \mathbb{R}^N$ learned per position. The $\tanh$ bounds $\tau \in [\epsilon, \epsilon + 2\tau_0]$, preventing collapse. Ablation compares against a fixed annealing schedule (e.g., $\tau$ decaying from 5 to 0.5).

**Teacher forcing.** Use a **random fixed sequence** as the forced prefix for both fault-free and fault-injected forward passes. This isolates fault-induced divergence without the unnecessary assumption that the reference must be generated by the fault-free model.

### 2.2 Optimization Objective (Revised)

Let $H \in \mathbb{R}^{M \times d}$ be the final hidden states (pre-projection) and $o_t \in \mathbb{R}^{|V|}$ the pre-softmax logits at position $t$. We define a **combined semantic-output representation**:

$$z = \text{concat}\left( \text{AttnPool}(H), \frac{1}{M}\sum_{t=1}^M o_t \right) \in \mathbb{R}^{d + |V|}$$

where $\text{AttnPool}(H) = \sum_{t=1}^M \alpha_t h_t$ with attention weights $\alpha_t = \text{softmax}(q^T h_t)$ and $q \in \mathbb{R}^d$ a learned query vector.

The objective maximizes the squared Euclidean distance between the combined representations of the fault-free and fault-injected models:

$$\mathcal{L} = -\|z^{\text{free}} - z^{\text{faulty}}\|_2^2$$

**Why this formulation:**

| Component | What it captures | Why it is needed |
|-----------|-----------------|------------------|
| **AttnPool(H)** | Sequence-level semantic meaning in the LLM's latent space | Directly optimizes for semantic divergence; learned query focuses on positions most affected by faults |
| **Mean-pooled logits** | Average output distribution tendency | Ensures sensitivity to **output-projection ($W_O$) and embedding-layer faults** that do not alter hidden states but change the output distribution |

Without the logits term, a fault corrupting $W_O$ (e.g., 600M parameters in a 4B model) would leave $H$ unchanged and the objective blind. The concatenation ensures coverage of all parameter layers.

**Implementation note:** The logits component is L2-normalized before concatenation to prevent the high-dimensional vocabulary term from dominating the $d$-dimensional semantic term.

### 2.3 Diagnostic: Hidden-State to Encoder Alignment

Before launching full ATPG optimization, we validate that the LLM's internal semantic representation is a faithful proxy for the Qwen3-Embedding detection space.

**Procedure:**
1. Sample $N_{\text{diag}} = 200$ diverse prompts (from WikiText-2 and random SDoT initializations).
2. For each prompt and $N_{\text{fault}} = 20$ randomly sampled faults:
   - Run fault-free and fault-injected LLM with teacher forcing.
   - Extract $d_h = \|\text{AttnPool}(H^{\text{free}}) - \text{AttnPool}(H^{\text{faulty}})\|_2^2$.
   - Decode outputs to text, embed via Qwen3-Embedding-0.6B: $d_e = \|e^{\text{free}} - e^{\text{faulty}}\|_2^2$.
3. Measure Spearman correlation $\rho(d_h, d_e)$.

**Conditional methodology:**

| Condition | Action |
|-----------|--------|
| **$\rho > 0.8$** | Proceed with the concatenated hidden-state + logits objective as defined above. |
| **$0.6 \leq \rho \leq 0.8$** | Add a lightweight learned linear adapter $W_a \in \mathbb{R}^{d \times d_{\text{emb}}}$ trained on the diagnostic data. The objective becomes $\mathcal{L} = -\|W_a(\text{AttnPool}(H^{\text{free}})) - W_a(\text{AttnPool}(H^{\text{faulty}}))\|_2^2$, with the logits term retained for output-projection coverage. |
| **$\rho < 0.6$** | Hidden-state proxy is unreliable. Fall back to using Qwen3-Embedding directly in the optimization loop: decode SDoT output to text (via straight-through or Gumbel-Softmax), embed, and maximize embedding distance. This requires discrete gradient estimation (higher variance) but preserves objective alignment. |

This diagnostic is run once per model family and reported in the evaluation section.

### 2.4 Joint Pattern Generation and Extraction

The joint optimization over $K$ patterns follows the standard ATPG formulation:

$$\{Z_1^*, \dots, Z_K^*\} = \arg\max_{\{Z_1, \dots, Z_K\}} \mathbb{E}_{f \sim p(f)}\left[\max_{k \in \{1,\dots,K\}} \|z_k^{\text{free}} - z_k^{\text{faulty}}\|_2^2\right]$$

After optimization, each $Z_k$ is discretized by sampling tokens. A discretization acceptance criterion is applied (retention ratio $\alpha$ comparing discrete vs. continuous divergence). For each accepted prompt $x_k$, we run the fault-free model $R$ times, embed the outputs using **Qwen3-Embedding-0.6B**, and record:
- Expected embedding: $e_k^* = \text{mean}_r(\text{Embed}(y_r))$
- Threshold: $t_k = \text{empirical quantile}_r(\|\text{Embed}(y_r) - e_k^*\|_2^2)$

## 3. Phase 2: Online Fault Detection (Black-Box)

Unchanged in structure. The deployer stores $(x_k, e_k^*, t_k)$ and queries the black-box LLM. For each query, the output is embedded via Qwen3-Embedding-0.6B and compared to $e_k^*$. A per-pattern majority vote over $R$ queries declares a fault if more than half exceed $t_k$.

**Why Qwen3-Embedding instead of SBERT:**
- **Performance:** MTEB 64.34 vs. ~56 for SBERT-all-MiniLM-L6-v2.
- **Compatibility:** Same tokenizer as our Qwen3 test models; no vocabulary mismatch.
- **License:** Apache-2.0, enabling self-hosted deployment without API dependencies.

## 4. Fault Sampling Motivation (Revised)

Physical faults are uniformly distributed over memory bits. However, neural network weights implicitly encode the training data distribution: weights with higher first-order sensitivity $S(p_n) = |p_n \cdot \partial \mathcal{L} / \partial p_n|$ are those that the model relies upon when processing in-distribution inputs. By biasing the fault distribution $p(f)$ toward high-sensitivity weights, we concentrate the test-generation budget on faults that affect active, information-carrying pathways.

**Without this bias**, a uniform sample over all parameter bits would allocate significant budget to weights in "dead" regions of the parameter space — weights that, when corrupted, merely produce garbled or out-of-distribution outputs. Such faults are not representative of the silent data corruptions that threaten functional safety in deployment, where the model operates on meaningful inputs. This skew is therefore a **test-generation design choice** that aligns the fault model with the operational regime of the deployed system. Evaluation still validates detection coverage against the true uniform physical fault distribution to ensure generalization.

## 5. Evaluation Plan

### Ablations

| ID | Ablation | Purpose |
|----|----------|---------|
| 1 | **Token-level L2 on softmax (original)** vs. **Concatenated hidden-state + logits (revised)** | Quantify coverage gain from semantic-level optimization |
| 2 | **KL divergence on softmax** vs. **L2 on concatenated representation** | Validate latent-space L2 over distribution divergence |
| 3 | **Learned $\tau$ (DLMI)** vs. **Fixed annealed $\tau$** | Address temperature collapse concern |
| 4 | **Random fixed teacher prefix** vs. **Fault-free-generated prefix** | Validate simplified teacher forcing |
| 5 | **Qwen3-Embedding** vs. **SBERT-all-MiniLM-L6-v2** | Measure impact of modern encoder |
| 6 | **Attention pooling** vs. **Mean pooling** vs. **Max pooling** | Test aggregation strategies |
| 7 | **With logits term** vs. **Hidden states only** | Quantify detection coverage of output-projection faults |

*Note: Ablation comparing uniform vs. sensitivity-weighted fault sampling is omitted. Sensitivity weighting is retained as a design choice motivated by the in-distribution fault model (§4).*

## 6. Complete Data Flow

### Offline Generation (White-Box)
```
Learnable SDoT Z ──soft embed──► LLM_θ (fault-free) ──┐
                                                      ├──► AttnPool(H) ──┐
LLM_θf (faulty) ──────────────────────────────────────┘                  ├──► concat ──► L2 distance ──► maximize
                                                      ├──► MeanPool(o) ──┘
       ▲                                      │
       └──────── teacher-forced prefix ◄──────┘
                                              │
                                    Random fixed sequence
```

**Diagnostic branch (pre-optimization):**
```
AttnPool(H_free) ──┐
                   ├──► Spearman ρ ──► conditional path (§2.3)
Embed(text_free) ──┘
```

### Online Detection (Black-Box)
```
(x_k, e_k*, t_k) ──► query black-box LLM (R times) ──► text {y_r}
                                                              │
                                                              ▼
                                                      Qwen3-Embedding
                                                              │
                                                              ▼
                                          majority vote over ||embed(y_r) - e_k*||^2 > t_k
```

## 7. Conclusion

The revised methodology directly addresses all feedback points:

1. **Objective alignment:** By optimizing divergence in a combined space of attention-pooled hidden states and mean-pooled logits, we directly target semantic output differences while remaining sensitive to output-projection faults.
2. **Encoder modernization:** Qwen3-Embedding-0.6B replaces SBERT, providing +8 MTEB points and tokenizer compatibility.
3. **Diagnostic validation:** The Spearman diagnostic with conditional methodology (direct optimization / adapter / fallback) ensures the hidden-state proxy is empirically justified, with graceful degradation if alignment is insufficient.
4. **Theoretical clarity:** Sensitivity-weighted sampling is motivated as an in-distribution fault model rather than a computational shortcut.
5. **Simplicity:** Teacher forcing uses a random fixed prefix; attention pooling replaces mean pooling as the default aggregation strategy.
